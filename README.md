# 📊 Data Science Lab Practicals

This repository contains practical implementations of core **Data Science concepts** using Python libraries such as **NumPy, Pandas, and Matplotlib**. The project demonstrates hands-on learning using real-world datasets like the **Titanic dataset** and an **E-commerce sales dataset**.

---

## 📖 Overview

The aim of this project is to build a strong foundation in:
- Data manipulation
- Numerical computation
- Data visualization
- Exploratory Data Analysis (EDA)

Each notebook focuses on specific concepts and their real-world applications.
